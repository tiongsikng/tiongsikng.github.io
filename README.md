# Tiong-Sik Ng — Research Portfolio

Source repository for the personal academic website of Tiong-Sik Ng, Assistant Professor in Cybersecurity at Xiamen University Malaysia.

**Website:** https://tiongsikng.github.io/

## Overview

The website presents information on research interests, publications, academic projects, teaching, professional experience, and education, primarily covering biometrics, computer vision, and cryptography.

## Website Features

- Responsive layouts for desktop and mobile devices
- Light and dark appearance modes
- Multilingual content in English, Korean, Japanese, and Chinese
- Interactive research visualizations and personalized graphics
- Academic publications, projects, and professional information

## Implementation

The website is built primarily with HTML, CSS, and JavaScript and is hosted using GitHub Pages.

The main files are:

- `index.html` — Website structure and content
- `css/site.css` — Styling and responsive layouts
- `js/site.js` — Theme switching, language selection, and interface functionality
- `images/` — Images and decorative assets
- `icons/` — Language and interface assets
- `files/` — Supporting documents
